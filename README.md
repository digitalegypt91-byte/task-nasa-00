# مِرصد | رصد الفيضانات من الفضاء

واجهة عربية لاستكشاف الأحداث المكتملة التي يصنفها NASA EONET ضمن فئة الفيضانات، مع خريطة فضائية تفاعلية عالية الدقة من Esri World Imagery.

## التشغيل

يتطلب Node.js 20.19+ أو 22.12+.

```powershell
npm install
npm run build
```

افتح `dist/index.html` مباشرة في المتصفح؛ لا يحتاج الموقع إلى خادم خلفي أو خادم تشغيل. يلزم اتصال بالإنترنت لجلب بيانات NASA EONET وصور Esri. للتطوير فقط، يمكن تشغيل `npm run dev` اختياريًا.

للمعاينة عبر خادم Vite أثناء التطوير فقط:

```powershell
npm run preview
```

## النشر على GitHub Pages

بعد رفع التغييرات إلى فرع `main`، فعّل **Settings → Pages → Build and deployment → Source → GitHub Actions**. سيبني سير العمل الموقع وينشره تلقائيًا عند كل تحديث للفرع.

عنوان الموقع: https://digitalegypt91-byte.github.io/task-nasa-00/

## مصادر البيانات وحدودها

- **NASA EONET**: يطلب التطبيق أحداث الفيضانات المكتملة المتاحة من الفئة `floods` عبر `https://eonet.gsfc.nasa.gov/api/v3/events?category=floods&status=closed&limit=5000`. يتحقق من نوع الحدث، التاريخ والإحداثيات قبل عرضه. تظهر معرّفات الجهات الأصلية في التفاصيل كنصوص غير قابلة للضغط.
- **Esri World Imagery**: طبقة صور فضائية عالية الدقة للخلفية التفاعلية. يظهر إسناد Esri ومصادر الصور على الخريطة.

لا يقدم التطبيق عدًّا للدول أو مساحة غمر أو شدة ما لم يرد ذلك صراحة في سجل الحدث. يعرض `status=closed` أحداث الفيضانات المكتملة التي يوفرها EONET، وليس قاعدة بيانات شاملة لكل فيضان وقع على الأرض. تاريخ جلب API هو وقت استلام الرد في المتصفح، وليس وقت تحديث NASA للكتالوج. عند نجاح الاتصال مع استجابة فارغة يعرض التطبيق صفر الأحداث في الأرشيف المتاح؛ وهذا لا يعني عدم وقوع فيضانات عالميًا. عند فشل الاتصال لا يعرض بيانات قديمة على أنها حديثة.

هذه الخدمات العامة لا تتطلب API key، لذلك لا توجد أسرار في الواجهة ولا حاجة إلى خادم وسيط لحمايتها.

## البنية

- `src/data/eonet.js`: جلب EONET والتحقق من الاستجابة ومعالجة الهندسة.
- `src/components/FloodMap.jsx`: خريطة Leaflet، طبقات الخلفية، وعرض تفاصيل الحدث.
- `src/App.jsx`: حالة الاتصال، الإحصاءات، المصادر والمنهجية.
- `src/styles.css`: الهوية البصرية العربية المتجاوبة.
